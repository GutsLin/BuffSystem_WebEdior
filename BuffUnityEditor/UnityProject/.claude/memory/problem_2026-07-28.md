# TEngine UI 文档差异记录

- **问题现象**：`ui-patterns.md` 示例使用 `RegisterButtonClick(button, callback)`，但当前项目的 `UIBase`、`UIWindow` 与 `UIWidget` 中不存在该方法，照抄会导致编译失败。
- **文档位置**：`.claude/skills/tengine-dev/references/ui-patterns.md` 的“完整 UIWindow 示例”。
- **正确 API**：当前项目使用 `button.onClick.AddListener(callback)` 注册按钮事件，并在窗口销毁时使用 `button.onClick.RemoveListener(callback)` 清理自身监听。
- **建议修正**：将示例改为当前实际 API，或先在 `UIBase` 中正式提供 `RegisterButtonClick` 封装后再保留原示例。
