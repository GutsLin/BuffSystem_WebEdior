大家好，本期视频介绍的是 Buff System，一个面向 Unity 和 TEngine 项目的状态效果配置与运行系统。这个项目解决的核心问题，是把策划侧的 Buff 配置、数据保存、Unity 数据导出，以及游戏中的运行验证连接成一条完整流程。整个仓库由网页编辑器和 Unity 运行时两个部分组成。网页端负责创建和管理配置，Unity 端负责读取配置并执行真正的战斗逻辑。

首先看一下项目结构。BuffWebEditor 是网页配置工具。前端使用 Vue 3、TypeScript、Vant 4 和 Pinia，服务端使用 Node.js、NestJS 和 TypeScript。配置可以由服务端持久化保存，并通过 Docker 和 Docker Compose 部署到云服务器。BuffUnityEditor 是基于 TEngine 的 Unity 工程，运行时使用 C Sharp 开发，并结合 YooAsset 加载配置资源。两个工程通过统一的 JSON 数据结构进行连接，尽量减少网页端和游戏端重复维护数据的问题。

进入网页后，默认打开的是英雄属性演示页面。这里采用了类似 Dota 2 的属性体系，包含力量、敏捷、智力三项基础属性，以及生命值、魔法值、攻击力、护甲、攻击速度、移动速度、生命恢复和魔法抗性等派生属性。以战意沸腾为例，添加效果后，英雄的力量和攻击速度会立即提高。力量变化还会继续影响生命上限和主属性攻击力，因此面板中的多个数值会同步更新。每一个有持续时间的效果都会显示剩余时间。倒计时结束后，Buff 会被正常移除，相关属性也会自动恢复，而不是永久保留在角色身上。

演示页面不仅能查看普通属性增减，还可以验证叠层、周期触发和状态控制。狂战士层数使用叠层策略，多次施加后会增加层数，并根据当前层数计算效果。腐蚀毒素是一个可以叠加的减益效果，它会按照设定的周期持续造成伤害。寒霜禁锢和震荡眩晕会给单位添加控制状态，运行时可以据此判断角色是否允许移动、攻击、施法或使用道具。法术护盾则提供减益免疫、魔法抗性和状态抗性。所有变化都会同步显示在属性面板、当前效果列表和战斗记录中，方便快速确认配置是否符合预期。

接下来是 Buff 配置管理页面。这里可以统一维护增益、减益、被动效果和光环，也可以通过名称搜索和类型筛选快速找到目标配置。编辑器中的基础字段包括唯一标识、显示名称、中文描述、效果类型、持续时间、最大层数、叠层策略、周期执行间隔、死亡移除规则和驱散规则。属性修改部分支持固定增加、百分比增加、百分比乘算、覆盖、最小值和最大值等运算方式。触发动作可以配置创建、销毁、周期、攻击命中、受到伤害等时机，并执行伤害、治疗、添加效果、移除效果或驱散等行为。完成修改后可以直接保存，也可以复制现有配置作为新效果的起点。

属性规则页面用于管理三维属性到派生属性的换算关系。例如，每点力量增加多少生命值，每点敏捷增加多少护甲和攻击速度，每点智力增加多少魔法值，以及主属性如何换算为攻击力。这些公式不会只存在于网页演示中，而是会和 Buff 配置一起进入 Unity 导出数据。导出页面会生成带有结构版本号的 JSON 文件，其中包含属性公式和完整的效果列表。Unity 端只需要读取这一份数据，就可以按照相同的规则进行计算，从而保证编辑器预览与游戏运行结果尽量一致。

现在进入 Unity 工程。项目启动时，Buff System Service 会通过 YooAsset 异步加载网页端导出的配置，并检查数据结构版本和必要字段。加载完成后，系统会创建 Buff 数据库和运行世界。战斗单位由 Buff Unit 表示，它负责保存基础属性、当前生命状态、活动效果和控制状态。运行时支持刷新、叠层、替换和独立实例四种叠加策略，也支持永久效果、周期触发、状态抗性、死亡移除、基础驱散和强驱散。伤害部分包含物理、魔法、纯粹和生命移除等类型，并通过 TEngine 的事件系统通知界面或其他游戏模块。

这是基于 TEngine UI 框架创建的 Buff 演示面板。左侧显示英雄的实时属性、行为权限和活动效果，右侧显示敌方单位状态与战斗日志，中间按钮用于触发不同测试。添加战意沸腾后，可以观察力量和攻击速度的变化。连续添加狂战士层数，可以确认叠层上限和剩余时间。腐蚀毒素用于验证周期伤害，寒霜禁锢用于验证控制状态，爆裂印记则用于验证效果结束或被移除时的触发行为。面板还提供物理攻击、魔法伤害、治疗与复活、强驱散、清除全部效果和重置演示等操作。通过这些功能，可以在一个界面中检查 Buff 的完整生命周期。

除了数值面板，项目还把 Buff 系统接入了实际玩家控制。Player Controller 使用 Rigidbody 2D 处理左右移动、跳跃、重力和落地检测，并驱动 Spine 的待机、移动和跳跃动画。角色朝向会根据输入自动翻转。玩家的世界移动速度不是固定值，而是根据 Buff Unit 中的移动速度属性动态换算，因此加速或减速效果可以直接反映到角色操作上。当角色处于眩晕、禁锢等禁止移动的状态时，控制器会停止水平移动和跳跃。玩家拾取带有 Buff Item 组件的道具后，道具配置的效果会自动施加到角色身上，实现配置、运行逻辑和场景交互的连接。

在部署方面，网页编辑器已经提供 Docker 和 Docker Compose 配置，可以部署到云服务器，并通过服务端文件和 Docker 数据卷保存配置。整个项目目前已经形成了从网页创建 Buff、保存配置、导出 JSON、Unity 加载数据，到运行时验证和玩家交互的完整闭环。后续还可以继续扩展技能系统、装备系统、可视化节点编辑、自动同步配置、特效绑定和多人战斗同步。以上就是 Buff System 项目的整体介绍，感谢观看。
