# Buff System Editors

本仓库用于统一管理 Buff 系统的 Web 配置编辑器和 Unity 编辑器。

## 目录结构

- `BuffWebEditor/`：Vue 3 + NestJS 的 Buff Web 编辑器。
- `BuffUnityEditor/`：预留的 Unity 项目目录。

## 在线访问

- Buff Web 编辑器：http://117.72.150.120:8082
- 域名：http://www.debugcat.cn（需完成京东云域名备案或合规放行后使用）

Web 项目的开发、构建和部署说明请查看 [`BuffWebEditor/README.md`](BuffWebEditor/README.md)。
